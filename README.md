# UD01_Actividad06_AdivinaNumero

Proyecto de consola desarrollado en Kotlin correspondiente a la actividad práctica de la Unidad Didáctica 1: **Adivina el Número**.

---

## 👤 Autora
- **Estudiante:** Inés Robles

---

## 📖 Descripción del Proyecto
El programa consiste en un juego interactivo por consola en el que el usuario debe adivinar un número generado aleatoriamente por la aplicación dentro de un rango específico. Proporciona pistas indicando si el número introducido es mayor o menor que el objetivo hasta dar con la solución.
